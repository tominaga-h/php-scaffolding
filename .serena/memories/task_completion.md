# タスク完了時のチェックリスト

## 必須項目

### 1. テストの実行
```bash
make test
```
または（コンテナ内で）:
```bash
composer test
```

### 2. 確認事項
- [ ] 新しいコードに対するユニットテストを追加したか
- [ ] 既存のテストがすべてパスするか
- [ ] コードスタイルが一貫しているか（タブインデント、PHPDoc）

## オプション

### コードカバレッジ確認
テスト後、`var/coverage/` にHTMLレポートが生成される

### Git操作
```bash
make push  # テスト実行後に自動でpush
```
